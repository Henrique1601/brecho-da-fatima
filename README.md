## 🌟 Visão Geral

O **Brechó da Fátima** é um marketplace desenvolvido com estética e experiência inspiradas em grandes marcas de moda e esporte (estilo Nike, Adidas e Zara), adaptado à realidade ágil e acolhedora do comércio local e brechós vintage:

* 🛍️ **Venda Direta sem Burocracia:** Elimina carrinhos complicados. Cada peça possui botão direto com link personalizado para negociação no WhatsApp com **Dona Fátima**.
* ❤️ **Sacola de Favoritos com Envio Agrupado:** A cliente marca os corações das peças desejadas e envia uma lista completa e somada direto no WhatsApp com um único toque.
* 🏷️ **Controle de Peça Vendida (`Vendido ✓` / `Disponível`):** Permite alternar o status instantaneamente. Peças vendidas exibem selo exclusivo e desabilitam botões de compra.
* 🤖 **Drag & Drop com IA de Catalogação:** Arraste de fotos com geração automática de títulos persuasivos, descrição, estado de conservação e hashtags para redes sociais.
* 📲 **Conexão com Buffer para Instagram:** Agendamento rápido de postagens e stories para o [@brechodafatimaa](https://www.instagram.com/brechodafatimaa?obrf=aHg0d2J1NHlucHhv).
* 📍 **Localização Física & Rotas:** Mapa interativo em Santos/SP com atalhos de 1 toque para **Google Maps**, **Waze** e solicitação de viagem no **Uber**.
* 🔐 **Segurança com PIN:** Proteção por senha (`1313`) para operações administrativas (cadastro de peças e marcação de vendido).

## 🚀 Como Rodar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Henrique1601/brecho-da-fatima.git
   cd brecho-da-fatima
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. Abra no navegador: [http://localhost:3000](http://localhost:3000)
